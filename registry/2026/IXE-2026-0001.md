# IXE-2026-0001 Engine cleanup cycle

## Metadata
- **ID:** IXE-2026-0001
- **Project:** ReCore
- **Severity:** S2 (Major)
- **Component:** [MEM]
- **Status:** ✅ Resolved
- **Reported:** 2026-08-25
- **Issue:** #4

## Description

Native memory leak may occur:
Engine.java:
```Java
// ...
public abstract void cleanup();

public void loop() {
    while (!window.isWindowShouldClose()) {
      update();
    }
    cleanup(); // May throw error!
    assetManager.cleanup(); //  Will be NOT performed after error
  }
```

Assets will be not deleted if AssetManager dont executes cleanup -> memory leak.

## Steps to Reproduce
```shell
1. Create project with ReCore
2. Create Application extending Engine
3. implement cleanup:
   
      public void cleanup() {
          throw new RuntimeException("Issue reproducing");
      }
   
4. Create Window, implement window close-on-button with Input
5. In Main class call Application loop, then press Window close-on-button
```

## Expected Behavior
Application extending Engine executes cleanup(), then executes cleanup() for its AssetManager.
