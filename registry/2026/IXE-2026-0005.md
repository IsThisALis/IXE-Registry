## Description

Window cleans after rendering and updates which brokes render.
```Java
while (!window.isWindowShouldClose()) {
      time.startFrame();
      update();
      window.clean(); // Problem!
      window.update();
    }
```

## Steps to Reproduce
```shell

```

## Expected Behavior
Window should clean in the start of cycle. Like this:
```Java
while (!window.isWindowShouldClose()) {
      window.clean();
      time.startFrame();
      update();
      window.update();
          }
```
